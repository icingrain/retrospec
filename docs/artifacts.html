Artifacts

Dashboard, exports, and MCP

Retrospec outputs are tied to daemon-owned local state, not scattered cache files.

Dashboard

The dashboard shows daemon health, registered projects, job ledger, analysis status, provider settings, uploads, and export previews. It is the fastest way to verify that a project is connected to the expected daemon and that retro/spec readiness is current.

Table exports

CSV and XLSX exports make structure and symbol analysis easy to inspect, share, and compare outside the dashboard.

Graph exports

GraphML is intended for graph tools such as Gephi and yEd. Cypher gives a draft import path for graph databases. Mermaid provides lightweight previews for README and design documents.

MCP read surface

The read-only MCP endpoint exposes project status and exploration tools to OpenCode-compatible clients. Agents can ask for readiness and anchors without writing daemon state or executing generated analysis directly.

Why this matters

All surfaces read the same daemon state. That keeps human review, agent prompts, exported files, and MCP responses aligned around evidence labels, support level, and missing capability notes.
