Install Guide

Agent install and daemon recovery

Use this when an OpenCode agent needs to install Retrospec or verify daemon state.

Basic flow

npm install -g retrospec-agent
cd /path/to/project
retrospec status .

retrospec status starts or refreshes the usable daemon when needed.

Checks

  • npm list -g retrospec-agent --depth=0
  • which retrospec
  • retrospec status .

Expected status

  • daemon: healthy (<installed-version>)
  • project: <current project path>
  • dashboard: http://127.0.0.1:<port>

Daemon recovery

If status points at an old version, identify the old Retrospec daemon and restart from the project.

ps aux | grep retrospec
lsof -nP -iTCP:<port> -sTCP:LISTEN
kill <old-daemon-pid>
retrospec status .
