Workflow

Status first. Daemon first. Evidence always.

Retrospec keeps AI work grounded in local analysis state before an agent changes source code.

1. Register the project

The daemon owns project state under .retrospec and records the current workspace, jobs, analysis readiness, exports, and dashboard endpoint.

2. Survey source evidence

Surveyor and retro analysis inspect structure, symbols, SQL, dependency, graph, complexity, and coverage signals. Unsupported or partial coverage is labeled instead of hidden.

3. Validate generated analyzers

When built-in skills are not enough, Retrospec narrows the task through interview, creates a source-fit analyzer, records a manifest, and requires validation evidence before execution.

4. Route through agent roles

Appraiser reviews generated evidence, Excavator submits approved daemon jobs, and Archivist handles exports and glossary reconciliation.

5. Read results through surfaces

Dashboard, CSV/XLSX, graph exports, and MCP tools all read daemon-owned state so humans and agents work from the same facts.
